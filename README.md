# Ledi Haustechnik GmbH — Demo-Website

Eine premium, einseitige Demo-Website für **Ledi Haustechnik GmbH**
(Geschäftsführer: Shpend Xhota).

## Ansehen

Einfach `index.html` im Browser öffnen — alles (CSS, JS, Fonts) ist
in der Datei enthalten, keine Installation nötig.

## Hero-Bild hinzufügen

Das Foto der Fußbodenheizung gehört in den Hero. Lege es als
**`hero.jpg`** direkt neben `index.html` ab — es wird automatisch
im Hero und im „Über uns“-Bereich verwendet. Fehlt die Datei, zeigt
die Seite einen eleganten dunklen Verlauf als Rückfall.

## Noch anzupassen (Platzhalter)

Diese Angaben sind aktuell Platzhalter und sollten ersetzt werden:

- Telefonnummer (`tel:+49000000000`)
- E-Mail (`info@ledi-haustechnik.de`)
- Adresse / Standort
- Impressum & Datenschutz (rechtlich für DE/AT/CH Pflicht)

Die Inhalte sind bewusst kurz und allgemein gehalten — eine
Demoversion zum Zeigen. Texte, Leistungen und Zahlen lassen sich
leicht erweitern.
